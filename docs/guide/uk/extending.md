Ядро лишається як є; **цільовий проєкт** будується на ньому - власні пакети
(DNP), міграції, команди, види процесів, UI і підтримка ШІ - і на ньому, у
свою чергу, можна будувати інший (напр. проєкт на пакетах акваріума).

## Новий проєкт

```
make new-project
```

запитує назву і теку (будь-де - `.env` записує, де ядро) і генерує проєкт з
`templates/target-project/`: власний git-репозиторій, compose-файли, образ UI,
Makefile, порожні `plugins/` і `migrations/`. Потім у новій теці:

```
make up-all
```

## Що додає проєкт

- **Типи пристроїв і вузлів** - пакет з контрактом, профілем пристрою EdgeX,
  правилами безпеки, елементами керування й симулятором в UI.
- **Види процесів** - `make add-process-kind KIND=<вид-шаблон>
  TARGET=<проєкт> [NEW_KIND=<назва>]` копіює шаблон процесу в `plugins/`
  проєкту; процес отримує схему конфігурації, команди, стан, сцену й аватари
  для Панелі.
- **Міграції** - початкові дані й таблиці, застосовуються при старті API.
- **UI** - `ui/register.js` пакета реєструє його панелі й компоненти Панелі;
  його тексти перекладаються у власних `ui/locales/`.
- **Підтримка ШІ** - маніфест пакета оголошує типи роботи, які отримують його
  екземпляри, і які з них можна запускати за розкладом; його промпти й
  інструменти.

## Переклади

Тексти інтерфейсу - англійські ключі в `t('...')`. Для нового коду:

```
node scripts/i18n-wrap.mjs <тека ui вашого пакета>
node scripts/i18n-check.mjs --write --plugins <ваш проєкт>/plugins
```

потім заповніть файли мов (`ui/locales/uk.json`, `de.json`, `es.json`).

Повний посібник - `docs/CREATING_A_TARGET_PROJECT.md` у репозиторії ядра.
