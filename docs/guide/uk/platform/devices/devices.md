![Сторінка «Пристрої»](screen:devices)

Кожен пристрій з його нодою, типом, значенням і часом показу; прострочені
значення підсвічено.

- **Значення** - наживо (без оновлення сторінки); одиниці; для пристрою, яким
  можна керувати, - ручне значення чи команда.
- **Авто / Вручну** - ресурс пристрою йде за процесами (Авто) або за значенням
  людини (Вручну); правила безпеки відхиляють заборонене поєднання.
- **Рядок** - розгорніть: інформація (бекенд, ім'я й статус в EdgeX,
  можливості, створено), налаштування значення, медіа (зображення камери),
  запис даних і контроль heartbeat.
- **Симульований** - значення симульованого пристрою можна задати на місці.
- **Групи** - групи пристроїв для бізнес-погляду.
