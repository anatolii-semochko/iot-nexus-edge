![Сервіс - Конфігурація - Панель](screen:service-config-dashboard)

**Панель** - дерево карток Панелі: додайте теку, аватар чи компонент,
переміщуйте їх, змінюйте картку - зображення, фон і рамку (див.
[Панель](../../../dashboard/)).

![Сервіс - Конфігурація - AI](screen:service-config-ai)

**AI** - підключення до моделей, рівні доступу екземплярів, календар запусків
за розкладом, токени MCP (див. [ШІ-асистент](../../../../ai/)).
