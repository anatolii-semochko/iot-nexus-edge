![Користувачі](screen:users)

Користувачі -> Користувачі: додайте людину (логін, ім'я, email, пароль),
призначте ролі, задайте токени ШІ на день (порожньо - без ліміту, 0 - ШІ
вимкнено), деактивуйте. Службові акаунти (оркестратор, симулятор, ШІ-агент) і
гість вбудовані.
