title: "Користувачі"

order: 1
---

![Користувачі](screen:users)

Користувачі -> Користувачі: додайте людину (логін, ім'я, email, пароль),
призначте ролі, задайте токени ШІ на день (порожньо - без ліміту, 0 - ШІ
вимкнено), деактивуйте. Службові акаунти (оркестратор, симулятор, ШІ-агент) і
гість вбудовані.

Обліковий запис MCP-клієнта (`mcp-...`, створюється разом із його токеном -
ШІ-асистент -> Підключення й MCP) теж тут: без пароля, він ніколи не входить;
його ролі задаються тут, як у людини (ніколи не роль з усіма правами).
