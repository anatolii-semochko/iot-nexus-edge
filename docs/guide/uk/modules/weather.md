![Сцена погоди](screen:weather)

Модуль погоди поєднує показання станції (температура, вітер, світло, дощ,
вологість, тиск) з прогнозом, який отримує сервер (Open-Meteo). Сцена показує
попередження наперед (мороз, штормові пориви, сильний дощ, спека), поточний
стан і сонячний день, наступні години й дні - сонце для PV (kWh/m²) і
градусо-дні опалення. Енергетичний план і планувальник опалення беруть
прогнози звідси.

Налаштування - місце, оновлення, пороги сцени (мороз, штормові пориви,
сильний дощ, спека, добрий / задовільний сонячний день, база опалення).
