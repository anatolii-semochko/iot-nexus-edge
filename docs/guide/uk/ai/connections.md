Сервіс -> Конфігурація -> AI: підключення до моделей - OpenAI, Anthropic чи
сумісний з OpenAI локальний сервер (Ollama, LM Studio, vLLM - дані лишаються
на об'єкті); ключ зберігається зашифровано й ніколи не показується; ліміт
відповіді й денний ліміт токенів на підключення; токени на людину на день
(Користувачі).

## MCP

Ті самі інструменти для будь-якого MCP-клієнта (напр. Claude Code):
Streamable HTTP за адресою `/api/mcp` з bearer-токеном, створеним у Сервіс ->
Конфігурація -> AI -> Доступ MCP. Токен показується один раз; зберігається
лише його хеш.
