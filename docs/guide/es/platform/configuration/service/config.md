![Servicio - Configuración - Panel](screen:service-config-dashboard)

**Panel** - el árbol de tarjetas del Panel: añada una carpeta, un avatar o un
componente, muévalos, edite una tarjeta: su imagen, fondo y marco (vea
[el Panel](../../../dashboard/)).

![Servicio - Configuración - AI](screen:service-config-ai)

**AI** - las conexiones a modelos, los niveles de acceso de las instancias, el
calendario de ejecuciones programadas, los tokens MCP (vea
[el asistente de IA](../../../../ai/)).
