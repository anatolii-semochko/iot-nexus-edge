![Roles](screen:roles)

Usuarios -> Roles: un rol es una tabla de lo que puede hacer:

- **Objetos** - cada instancia de proceso (un campo energético, un sistema de
  calefacción, un acuario) y «todos los demás objetos», con un nivel: ver,
  controlar, configurar (y los niveles de la IA);
- **Secciones** - las áreas del sistema (dispositivos, registros, usuarios,
  servicio, ...);
- **Páginas** - qué páginas muestra el menú (un rol puede mostrar solo el
  Panel: entonces no hay menú).

Una persona con varios roles actúa en uno a la vez - **Actuar como** en el
menú de usuario; la cabecera muestra el rol actual. Un enlace con
`?account=<nombre de enlace del rol>` abre la aplicación en ese rol.
