title: "Invitado"

![Invitado](screen:guest)

Usuarios -> Invitado: active el invitado para que los visitantes entren sin
iniciar sesión, con un rol predeterminado (p. ej. un visitante de solo
lectura). Las elecciones del invitado (como el idioma) se quedan en su propio
navegador.

- **Acceso de invitado activado** - si hay invitado o no; desactivado: todos
  inician sesión.
- **Un visitante nuevo empieza como** - el rol que recibe un visitante (lo que
  ve, qué páginas, los tokens de IA al día para todos los visitantes juntos:
  Usuarios -> la cuenta `guest`). Un enlace con `?account=<nombre de enlace de un
  rol>` abre otro rol de invitado.
- **Quién los lee** - las conversaciones de los visitantes con la IA: **Privadas:
  cada navegador las suyas** o **Públicas: cada invitado lee todas**.
- **Conservar, días** - cuánto se guardan las conversaciones de un visitante
  (vacío: siempre).
- **Solo se mantienen las preguntas relevantes** - una pregunta ajena al sistema
  no se responde ni se guarda (sus tokens cuentan igual).
