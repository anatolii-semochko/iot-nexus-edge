![Asistente de IA](screen:ai-assistant)

El asistente de IA trabaja con todo el sistema o con una instancia de un
paquete (un campo energético, un sistema de calefacción, un acuario). Lee el
sistema mediante herramientas - estados, avisos y errores, registros, series
temporales, configuraciones, esta documentación - y propone o hace cambios
dentro de sus niveles de acceso.
