**Dashboard** - the tree of the Dashboard's cards: add a folder, an avatar or a
component, move them, edit a card - its picture, background and frame (see
[the Dashboard](../../../dashboard/)).

![Service - Config - AI](screen:service-config-ai)

**AI** - the model connections, the instances' access levels, the calendar of
scheduled runs, the MCP tokens (see [the AI Assistant](../../../../ai/)).
