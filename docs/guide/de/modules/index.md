Jedes Modul ist ein Satz von Paketen - seine Geräte, Knoten und Prozesse,
ihre Szenen im Dashboard, Einstellungen und KI-Unterstützung. Grüne Energie
und Heizung steuern die Ressourcen des ganzen Standorts; das Aquarium zeigt
präzise Steuerung auf niedriger Ebene für ein spezialisiertes System. In die
Demo kommen weitere Module: eine Lackiererei mit Pneumatik, ein offenes Feld,
ein Gewächshaus.
