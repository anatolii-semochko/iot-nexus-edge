![Aquarium](screen:aquarium)

Die Aquarium-Pakete führen ein Pflanzenaquarium (oder eine Flotte von Becken)
von Anfang bis Ende. Das Dashboard eines Beckens zeigt sein Licht, seine
Live-Anzeigen und Ausstattung, den Unterschrank mit Foto und die fällige
Wartung.
