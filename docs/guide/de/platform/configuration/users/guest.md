![Gast](screen:guest)

Benutzer -> Gast: schalten Sie den Gast ein, damit Besucher ohne Anmeldung
hineinkommen, mit einer Standardrolle (z. B. ein Besucher, der nur liest). Die
Einstellungen des Gastes (etwa die Sprache) bleiben in seinem eigenen
Browser.

- **Gastzugang an** - ob es den Gast überhaupt gibt; aus - alle melden sich an.
- **Ein neuer Besucher beginnt als** - die Rolle, die ein Besucher bekommt (was er
  sieht, welche Seiten, die KI-Tokens pro Tag für alle Besucher zusammen -
  Benutzer -> das Konto `guest`). Ein Link mit `?account=<Linkname einer Rolle>`
  öffnet eine andere Gastrolle.
- **Wer sie liest** - die KI-Gespräche der Besucher: **Privat - jeder Browser
  eigene** oder **Öffentlich - jeder Gast liest alle**.
- **Aufbewahren, Tage** - wie lange die Gespräche eines Besuchers bleiben (leer -
  immer).
- **Nur relevante Fragen behalten** - eine Frage, die nichts mit dem System zu
  tun hat, wird nicht beantwortet und nicht gespeichert (ihre Tokens zählen
  trotzdem).
