![Benutzer](screen:users)

Benutzer -> Benutzer: eine Person hinzufügen (Benutzername, Name, E-Mail,
Passwort), Rollen geben, ihre KI-Tokens pro Tag festlegen (leer - unbegrenzt,
0 - KI aus), deaktivieren. Dienstkonten (der Orchestrator, der Simulator, der
KI-Agent) und der Gast sind eingebaut.
