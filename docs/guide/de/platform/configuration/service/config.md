![Service - Konfiguration - Dashboard](screen:service-config-dashboard)

**Dashboard** - der Baum der Dashboard-Karten: einen Ordner, einen Avatar
oder eine Komponente hinzufügen, verschieben, eine Karte bearbeiten - Bild,
Hintergrund und Rahmen (siehe [das Dashboard](../../../dashboard/)).

![Service - Konfiguration - AI](screen:service-config-ai)

**AI** - die Modellverbindungen, die Zugriffsstufen der Instanzen, der
Kalender der geplanten Ausführungen, die MCP-Tokens (siehe
[den KI-Assistenten](../../../../ai/)).
