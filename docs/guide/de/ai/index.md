![KI-Assistent](screen:ai-assistant)

Der KI-Assistent arbeitet mit dem ganzen System oder mit einer
Paketinstanz (einem Energiefeld, einem Heizungssystem, einem Aquarium). Er
liest das System über Werkzeuge - Zustände, Warnungen und Fehler,
Protokolle, Zeitreihen, Konfigurationen, diese Dokumentation - und schlägt
Änderungen innerhalb seiner Zugriffsstufen vor oder nimmt sie vor.
