---
title: "Scheduled runs"
description: "The calendar - work types run on a schedule."
order: 3
---

Service -> Config -> AI -> the calendar: runs of a work type on a schedule
(daily, every N hours, weekly, monthly), e.g. the Energy Ledger's day plan or
the heating plan. A run's warnings link to its conversation.

**Add a scheduled run**: the work type (only those its package allows on a
schedule), **Repeat** - every day, every N hours, every week (the days),
every month (the day), every year; the time. The list: the next and the last
run, **Run now**, **Delete**. An instance with no connection skips its runs -
the calendar says so. The runs' tokens count in Logs -> AI usage as
"Schedules".
