![AI Assistant](screen:ai-assistant)

The AI Assistant works with the whole system or with one package instance
(an energy field, a heating system, an aquarium). It reads the system through
tools - states, warnings and errors, logs, time series, configurations, this
documentation - and proposes or makes changes within its access levels.
